About this tool

Color Palette Generator builds matching colour schemes from a base colour: analogous, complementary, split complementary, triadic, tetradic and monochromatic. Click a swatch to copy its hex code, or copy ready-made CSS variables. Everything runs in your browser.

How to use it

  1. Pick a base colour or type a hex code.
  2. Choose a colour scheme.
  3. Click swatches to copy hex codes, or copy the CSS variables.

Frequently asked questions

What is an analogous palette?

Colours next to each other on the colour wheel. They look calm and harmonious.

How do I find a good base colour?

Use Random base colour until something appeals, then try the different schemes.
